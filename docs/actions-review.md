# 新增 500 个头像动作模板复核

2026-10-24 新增 500 个模板，保留原有 120 个模板。新模板均只接受一张头像、零段文字，输出 512×512；其中 194 个为循环 GIF，306 个为 PNG。来自 45 个公开图集，逐图来源、固定提交、原图 SHA256、裁切记录和素材 SHA256 见 [来源清单](../ASSET_SOURCES.md) 与 `memes/mantou_actions/templates.json`。

## 对齐与筛选

- 对候选底图和替换后的画面做视觉对照；保留帧全部放入检查面板，用纯色头像暴露原眼睛、嘴巴残留和位置漂移。选择通过复核的 500 个不同底图，未将别名计为模板。
- 人物使用人脸特征点定位，并按眼睛连线调整倾斜角度；动图逐帧保存坐标和角度。检测到手掌、海报、衣服、单只眼睛等错误目标，或中途切换到其他人物的候选被剔除。
- 卡通使用经修正的头部坐标或轮廓蒙版。明显遮住手势、切掉关键道具、露出原眼睛和嘴巴的候选被剔除；水面遮挡按所在帧保留前景，不在完全潜水的帧上悬空粘头像。
- 原字幕通过裁切或清理文字区域去除。画面中的服装印花、商标和背景招牌等原物件细节可能保留；生成器不添加文字。
- 动图优先。新模板最多保留 12 帧，采样时合并帧时长；只剩原脸表情变化、字幕或水印闪动的素材转为 PNG 或剔除。原始两三帧图不计作本批动作 GIF。未用单帧 GIF 充数。

## 可重复检查

`python -m pytest -q` 使用真实 Python 版 meme-generator 加载整个库并生成全部 620 个模板。新模板另检查：

- 恰好 500 个独立键名、500 个不同源图 SHA256、500 个不同裁切素材 SHA256，与此前 100 个网络底图的源图不重复。
- 素材实际帧数与逐帧坐标数量一致，矩形和轮廓位于图像范围内；静态和动态输出类型一致。
- 根据保存的眼睛、鼻子和嘴巴特征点检查实际覆盖结果，避免只测试头像框中心而漏掉偏移。
- 轮廓角落、旋转填充和前景遮挡的组合，以及头像数量和文字输入的拒绝行为。
- 较宽的卡通头型先将头像裁成正方形，再映射至头部比例，避免直接裁成扁矩形时丢失头像下沿；原有模板保持原来的映射方式。

自动检查不能判断每个头像的内容是否适合构图。任意图片作为头像时会按模板的头部形状裁切；宽头像的边缘内容可能被裁掉。完整预览见 [新增 500 个目录](../ACTIONS_CATALOG.md)，旧模板的复核记录见 [此前 100 个复核](alignment-review.md)。

开发阶段的人脸模型和图像处理工具不随库分发，也不在运行时执行。运行只依赖已有的 meme-generator 和 Pillow。
